## Description

Everyday PDF tools in your browser, with local processing and no file upload.

- Convert JPG, PNG and WebP images into a PDF.
- Export PDF pages as PNG or JPG images in a ZIP.
- Merge PDF documents.
- Extract or reorder selected pages.
- Rotate selected pages.

No account or subscription is required. Your files stay in the extension tab's memory until cleared or the tab is closed. Download the result to your device. There is no OCR, PDF-to-Word, password removal or cloud conversion. Encrypted or damaged documents may not be supported. File-count/size limits are shown in the UI.

An optional, clearly labelled business-service link lets you request a quote for custom document automation. It is separate from these free tools. Selected files and names are never sent with that link.

## Privacy practices draft

Single purpose: Convert and organize files selected by the user locally, then download the requested PDF/image output.

No extension or host permissions. The MV3 service worker only opens the bundled tools page when the toolbar icon is clicked. Processing uses bundled pdf-lib and PDF.js, including local workers/decoders; PDF scripting/evaluation is disabled. No remote code or uploads.

Disclose handling of user-selected file/document content even though it is local-only. Do not certify that no data is handled. Select current dashboard data-type categories that match document content and describe its local-only use. No data sale, unrelated use/transfer, or lending use.
