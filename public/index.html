How does the shop checkout work?

The storefront saves order requests on the server. Fulfilment and payment are confirmed by Xender Secrets after the order is submitted.

Can you build a complete frontend + backend website?

Yes. The website catalog includes frontend, backend/API and connected full-stack builds that can be adapted to a real project.

Are the novels copied onto this website?

No. The classics library links to Project Gutenberg source editions instead of republishing copyrighted material.

Does the chatbot cost money per message?

The current Xender Assistant is rule-based and does not use a paid AI API.
