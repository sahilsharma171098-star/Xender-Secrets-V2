# Changelog

## 1.0.0 — 2026-10-06
First release.

- One-click audit of the current page with a deterministic 0–100 Website Health Score across SEO, Accessibility, Usability, Conversion and Technical basics
- 47 local checks, each with "why it matters" and "recommended fix"
- Conversion checks clearly labelled as heuristics
- Measured contrast check, limited to solid backgrounds
- User-triggered same-site broken link check that reports only verified 404, 410 and 5xx responses
- Copy a plain-text report
- Friendly handling of browser-protected pages, extension stores and PDFs
- Light and dark mode
- Permissions: activeTab and scripting only
- Builds for Edge, Firefox and Chrome from one shared source
